## 使用规则（agent 必读）

1. **先分诊主体**：用户项目由集团本部还是金电信科组织采购，决定用 `group/` 还是 `jdxk/`；不明确时在报告"待人工确认"中列出，两套阈值都要提示。
2. **条文引用格式**：《制度全称》第 X 条（或附件 N），禁止只写"公司规定"。条号以 md 文件内 `**第X条**` 标记为准。
3. **效力顺序**：国家法规（L0~L2）> 集团制度（G）> 公司制度（J）。内部制度判定不称"违法"，称"违反公司/集团制度"。
4. **版本时效**：J 口径制度废止 2024 年版（金电信科字〔2024〕24 号），G 口径废止 2022 试行版（金电字〔2022〕23 号）。引用时注意新旧差异（如 J 采购管理规定 2025-05-21 施行、分散采购办法 2025-05-14 施行）。
5. **制度未覆盖**仍须按 SKILL.md 判定铁律标"存疑/待人工确认"，不得以国家法规默认替代内部制度结论。
