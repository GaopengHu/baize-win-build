# 输出格式样例

以下为脱敏虚构内容，仅示意输出格式。实际转写命令见上级 SKILL.md。
本地引擎 v2.1 起为 FunASR Paraformer-Large（默认 INT8 量化 ONNX；说话人分离走完整版 CAM++），输出形态不变。

## .srt 格式（带说话人标注 + 时间戳）

`--diarize` 输出形态（说话人由 CAM++ 自动聚类，按首次出现顺序编号）：

```
1
00:00:02,000 --> 00:00:14,500
[发言人1] 各位领导上午好，今天经营分析会准时开始，先请财务口通报上半年情况。

2
00:00:15,000 --> 00:01:02,000
[发言人2] 上半年营业收入同比增长，但应收账款周转放缓，现金流压力主要集中在二季度。

3
00:01:03,000 --> 00:01:09,000
[发言人1] 这个问题上次会就提过，请项目口说一下回款进度。

4
00:01:10,000 --> 00:01:25,000
[发言人3] 在手三个项目里，两个已进入验收，回款预计三季度到账。
```

## .txt 格式（纯文字稿，顶部含水印）

`--formats txt` 输出形态：

```
[本文为 ASR 机器转写，专名/数字/口径以原音频为准，未经人工校对]

[00:00:02] [发言人1] 各位领导上午好，今天经营分析会准时开始，先请财务口通报上半年情况。
[00:00:15] [发言人2] 上半年营业收入同比增长，但应收账款周转放缓，现金流压力主要集中在二季度。
[00:01:03] [发言人1] 这个问题上次会就提过，请项目口说一下回款进度。
[00:01:10] [发言人3] 在手三个项目里，两个已进入验收，回款预计三季度到账。

注：发言人标号由 CAM++ 自动聚类生成，非真实姓名；交付纪要前须核对领导姓名/职务。
```

## 格式说明
- **.srt**：标准字幕格式，带序号 + 时间戳 + 说话人标注，可直接加载到视频播放器。
- **.vtt**：Web 字幕格式，类似 srt 但时间戳用 `.` 分隔，头部有 `WEBVTT`。
- **.txt**：纯文字稿，顶部强制水印，适合直接喂给纪要/访谈整理流程。
- 说话人标号（发言人1/2/3...）由 CAM++ 自动生成，**非真实姓名**，交付前须人工核对。
