# 历年常用表述库（按语境分类）

> 用途：收录国央企公文中历年高频出现的表述，按语境分类，供措辞选用与语境匹配。适用于工作总结、述职、汇报、部署等各类材料。
> 加载时机：措辞润色、需要提升表述规范性时，加载本文件对应语境章节。
> 使用原则：结合具体业务实际选用，同一篇材料中同一类表述避免高频重复。

---

## 一、成效表述类

### 总体成效（年度/阶段总结用）
- 稳中有进、稳中提质、稳中向好
- 保持良好发展态势
- 呈现量质齐升的良好局面
- 实现历史性突破/跨越式发展
- 迈上新台阶、实现新提升、取得新成效
- 交出了一份……的合格答卷

### 增长与提升
- 同比增长/环比增长/逆势增长
- 保持两位数增长
- 增速高于……X 个百分点
- 占比提升至 XX%
- 完成率/达成率 XX%

### 质量与效益
- 盈利能力稳步增强
- 运行质效持续改善
- 资产质量进一步夯实
- 结构不断优化、动能持续转换
- 投入产出效率明显提高

**选用提示**：成效表述要与数据搭配（"同比增长 XX%"），避免只有定性没有定量；同一段落避免连用两个"持续"。

## 二、问题表述类

### 问题归纳（述职/总结用）
- 一是……；二是……；三是……（标准三段式）
- 主要表现在：理论学习不够深入、创新意识有待增强、工作落实仍有差距
- 存在……的短板弱项
- 与……相比仍有较大差距
- 距离……要求还有一定距离

### 委婉措辞（官方惯用）
- 有待进一步加强/尚需持续提升/还需不断深化
- 存在不足/仍有差距/还不平衡不充分
- 一定程度上存在……现象

**选用提示**：问题表述要具体到事项（"对基层调研指导不够"），避免空泛的"存在不足"四字带过；涉密、敏感问题不写入正式材料。

---

## 三、部署要求类

### 总体要求（方案/部署用）
- 坚持……原则/落实……要求/围绕……目标
- 以……为主线/以……为抓手/以……为牵引
- 统筹推进……/协调推进……/一体推进……
- 着力在……上下功夫/着力破解……难题

### 分项部署
- 要……，要……，要……（排比推进）
- 持续深化……/纵深推进……/扎实推进……
- 全力抓好……/重点抓好……/突出抓好……
- 压紧压实责任/细化实化举措/强化跟踪问效

### 责任与落实
- 挂图作战、倒排工期、对表推进
- 清单化管理、项目化推进、节点化考核
- 定人、定责、定时限（"三定"）
- 闭环管理：部署→落实→督查→反馈

**选用提示**：部署类动词（推进/深化/抓好）注意变换，避免"深入推进"全文出现 5 次以上；每条部署尽量对应可考核的具体抓手。

## 四、表态承诺类

### 坚定表态（发言/承诺用）
- 坚决贯彻……/坚决落实……/坚决扛起……
- 不折不扣落实……/雷厉风行落实……/一以贯之落实……
- 以钉钉子精神抓好落实
- 定了就干、马上就办、办就办好
- 做到件件有着落、事事有回音

### 决心与信心
- 以更加昂扬的斗志/以更加务实的作风/以更加有力的举措
- 坚定信心、鼓足干劲、乘势而上
- 在……中彰显担当作为
- 为……贡献更大力量

**选用提示**：表态要结合本单位实际（"立足本职岗位"），避免口号化；承诺事项要与前面问题一一对应。

## 五、结语收尾类

### 报告类结语
- 特此报告。
- 以上报告，请审阅。
- 妥否，请批示。（请示类）
- 特此请示，恳请批准。

### 总结类结语
- 让我们更加紧密地团结在以习近平同志为核心的党中央周围……
- 为推动公司高质量发展而努力奋斗
- 以优异成绩迎接……/为……作出新的更大贡献

### 通知类结语
- 本通知自印发之日起施行。
- 请遵照执行/请认真贯彻执行。
- 执行中遇到的问题，请及时反馈。

**选用提示**：结语与文种严格对应（请示用"请批示"、报告用"请审阅"）；宣传鼓动类结语用于发言稿/总结，日常事务性文件不用。

## 六、公文高频动词替换表（避免口语化）

| 口语表达 | 规范表述 |
|---------|---------|
| 搞 | 开展、推进、组织 |
| 弄 | 办理、处理 |
| 做 | 实施、落实、开展 |
| 干 | 实施、推进 |
| 整 | 整治、规范、完善 |
| 抓 | 落实、推进、强化（"抓好"可保留） |
| 想办法 | 多措并举、综合施策 |
| 差不多 | 基本、较为、大体 |
| 很多 | 较大幅度、显著、大量 |
| 特别 | 尤为、十分、显著 |

## 七、表述搭配自查清单

1. **动词搭配**："推进"配"工作/改革/建设"，"深化"配"改革/认识/融合"，"强化"配"责任/监管/保障"
2. **不叠用**：避免"进一步深化推进""持续不断加强"等叠床架屋
3. **数据佐证**：每个定性表述尽量有定量支撑（"成效显著"→"同比增长 XX%"）
4. **口径一致**：同一指标全文统一（增长基数、同比/环比口径）
5. **对标检查**：政治术语对照 `vocabulary-guide.md` 第一章，不可自行修改
