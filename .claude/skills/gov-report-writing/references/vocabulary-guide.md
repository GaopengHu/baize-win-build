## 二、公文常用句式

### 开头句式
- "为深入贯彻落实……精神，根据……要求，结合……实际，现就……通知如下："
- "按照……部署，……现提出如下意见："
- "经……研究，决定……"
- "……已收悉。经研究，现将有关意见函复如下："
- "202X年以来，在……的正确领导下，……坚持以……为指导，紧紧围绕……中心任务……"

### 过渡句式
- "现将有关情况报告如下："
- "重点抓好以下几个方面工作："
- "具体安排如下："
- "重点从以下几个方面着力："
- "现提出如下建议："

### 总结句式
- "总的来看，……"
- "综上所述，……"
- "通过……，取得了以下成效："
- "实践证明，……"

### 要求/部署句式
- "要……，要……，要……"（排比）
- "坚决做到……"
- "着力抓好……"
- "扎实推进……"
- "持续深化……"
- "进一步……"（使用频率最高的公文修饰语）

### 问题表述句式（述职/总结用）
- "主要表现在：一是……二是……三是……"
- "究其原因，主要有：……"
- "对标……要求，还存在……的差距"
- "与……相比，在……方面还需加强"
- "……工作仍存在薄弱环节"

## 五、安全保密注意事项

### 涉密信息处理
1. **绝对禁止在AI对话中透露涉密内容**
2. **禁止输入密级文件原文或摘要**
3. 可以描述场景和要求，但不引用涉密原文：
   - ✅ "撰写一份关于装备保障工作的年度总结，结构包括……"
   - ❌ "根据《XX装备2025年保障方案》（机密），请帮我……"
4. 不使用真实人名、具体项目编号、关键技术参数
5. 输出文档中的"XX"占位符需人工替换为真实信息

### 敏感内容规避
- 不涉及国防、军工、前沿科技等敏感领域的具体细节
- 不涉及组织架构、编制等内部管理信息
- 不提及未公开的政策走向或决策信息
- 不引用内部文件编号和密级标注

## 六、格式与排版微操

### 数字用法
- 公历世纪、年代、年月日、时刻用阿拉伯数字：2025年7月
- 统计表中的数值用阿拉伯数字
- 定型的词/词组/成语用汉字：一律、一方面、星期五
- 两个数字并列连用表示概数用汉字：三五天、七八十人

### 标点符号
- 正文中各层级序号后标点：
  - 一、二、三 → 顿号
  - （一）（二）（三） → 不加标点
  - 1. 2. 3. → 下脚点（英文句号）
  - （1）（2）（3） → 不加标点
- 公文标题一般不加标点符号（除法规名称加书名号外）

### 引用规范
- 引用公文先引标题后引发文字号：根据《国务院关于……的通知》（国发〔2025〕1号）
- 引用法律法规：根据《中华人民共和国……法》
- 年份一律用全称：2025年（非"25年"）

### 禁用词汇
- ❌ 口语化词汇：搞、弄、做、干、整
- ❌ 绝对化词汇：完全、绝对、100%
- ❌ 夸张修辞：史无前例、前所未有
- ❌ 情绪化表达：非常、特别、极其

### 推荐替代词
| 口语/非正式 | ✅ 正式公文替代 |
|-------------|----------------|
| 搞 | 开展、推进 |
| 弄 | 办理、处理 |
| 做 | 实施、执行 |
| 很多 | 较大幅度、显著 |
| 有点 | 一定、部分 |
| 不够 | 有待加强、尚需提升 |
| 没做好 | 存在不足、尚有差距 |
