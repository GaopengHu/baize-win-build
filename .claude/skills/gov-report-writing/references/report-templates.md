# 国央企常用报告模板框架

## 一、年度工作总结

```
一、主要工作及成效
    （一）[业务板块一]：成效概述 + 关键数据 + 典型案例
    （二）[业务板块二]：成效概述 + 关键数据 + 典型案例
    （三）[业务板块三]：成效概述 + 关键数据 + 典型案例

二、重点工作亮点
    （一）[亮点一]
    （二）[亮点二]
    （三）[亮点三]

三、存在的问题与不足
    （一）[问题一]：描述 + 原因分析
    （二）[问题二]：描述 + 原因分析
    （三）[问题三]：描述 + 原因分析

四、下一步工作计划
    （一）[目标一]：具体措施
    （二）[目标二]：具体措施
    （三）[目标三]：具体措施
```

### 写作要点
- 小标题对仗工整，多用动宾结构
- 数据具体化：增长率、完成率、同比增长等
- 问题分析不回避、不夸大、有对策
- 下一步计划要可量化、有时限、有责任人

```
    （三）团队建设管理方面
    （四）廉政建设方面

    （一）[亮点一]
    （二）[亮点二]

三、问题与不足
    （一）理论学习深度不够
    （二）[业务方面不足]
    （三）[管理方面不足]

四、改进措施与努力方向
    （一）加强理论学习
    （二）提升业务能力
    （三）改进工作作风
```

### 写作要点
- 第一人称，语气谦逊务实
- 既不夸大成绩也不过分自贬
- 问题部分要体现反思深度
- 改进措施要具体可落实

```
二、存在问题
    （一）[问题一]
    （二）[问题二]
    （三）[问题三]

三、下一步工作思路
    （一）[措施一]
    （二）[措施二]
    （三）[措施三]
```

### 写作要点
- 政治站位高，语态庄重严肃

- 避免空话套话，结合具体工作谈党建

## 四、调研报告/课题研究

```
摘要（200字以内）

一、调研背景与目的
    1.1 政策背景
    1.2 调研目的
    1.3 调研方法（问卷/访谈/实地考察/数据采集）

二、现状分析
    2.1 基本情况
    2.2 主要特点
    2.3 数据呈现（可用表格）

三、存在的问题及原因分析
    3.1 [问题一]
        3.1.1 具体表现
        3.1.2 原因剖析
    3.2 [问题二]
    ...

四、对策建议
    4.1 [建议一]
    4.2 [建议二]
    4.3 [建议三]

五、结论与展望
```

### 写作要点
- 数据驱动，定性与定量结合
- 问题分析要有深度，不浮于表面
- 对策建议要可操作、有创新
- 引用权威数据源和政策文件
- 建议引用"十四五"规划、行业白皮书等权威依据

```
一、总体要求

    （二）基本原则
    （三）工作目标（含量化指标）

二、主要任务
    （一）[任务一]
    （二）[任务二]
    （三）[任务三]

三、实施步骤
    （一）动员部署阶段（X月X日—X月X日）
    （二）全面推进阶段（X月X日—X月X日）
    （三）总结评估阶段（X月X日—X月X日）

四、责任分工
    （一）牵头部门：[XX部]，负责[XX]
    （二）配合部门：[XX部]，负责[XX]
    （三）监督部门：[XX部]，负责[XX]

五、保障措施
    （一）组织保障
    （二）经费保障
    （三）技术保障
    （四）制度保障

```

### 写作要点
- 目标要SMART（具体、可衡量、可达成、相关、有时限）
- 责任要落实到具体部门/个人
- 时间节点要明确
- 保障措施要具体，不说"加强领导"之类的空话

## 七、通知/公告

```
[发文机关标志]
[发文字号]

[标题]

[主送机关]：

[正文：事由 + 具体内容 + 要求]

附件：[附件名称]

[发文机关署名]
[成文日期]
（印章）
```

### 写作要点
- 开门见山，一事一通知
- 时间、地点、对象三要素必须明确
- 语言准确无歧义
- 命令性通知用语：必须、务必、不得
- 告知性通知用语：请、望、希

## 九、函

```
[发文机关标志]
[发文字号]

[标题]

[主送机关]：

[正文：缘由 + 事项 + 结语]

特此函告。
（或：专此函商。/ 请即函复。/ 特此函复。）

附件：[附件名称]

[发文机关署名]
[成文日期]
```

### 适用场景
- 去函：向平级或不相隶属机关商洽工作、询问问题
- 复函：答复对方来函所提问题
- 告知函：将有关事项告知对方

### 写作要点
- 一事一函，不夹杂多项不相关事务
- 语气平等谦和，不居高临下也不卑不亢
- 去函结语常用「请即函复」「盼复」；复函结语用「特此函复」
- 标题通常为「关于……的函」
- 正文开门见山，先写缘由再写事项

---

## 十、请示

```
[发文机关标志]
[发文字号]           签发人：[姓名]

[标题]

[主送机关]：

[正文：缘由 → 事项 → 结语]

妥否，请批示。
（或：以上请示如无不妥，请批准。/ 妥否，请审批。）

附件：[附件名称]

[发文机关署名]
[成文日期]
```

### 适用场景
- 请求上级对某项工作作出指示
- 请求上级批准某事项
- 请求上级解决具体困难

### 写作要点
- **一事一请**：一份请示只涉及一个事项，便于上级批复
- 缘由充分：说明为什么要请示，提供必要的背景和依据
- 方案明确：提出的意见或方案具体可操作
- 主送一个机关：请示只能主送一个上级机关
- 不得越级请示（特殊情况除外，须抄送被越过的机关）
- 「签发人」必须标注（上行文要求）
- 请示与报告的区分：请示需要批复，报告不需要

---

## 十一、批复

```
[发文机关标志]
[发文字号]

[标题]

[主送机关]：

[正文：引述来文 → 批复意见 → 结语]

此复。
（或：特此批复。）

[发文机关署名]
[成文日期]
```

### 适用场景
- 审批下级机关的请示事项
- 对下级的政策理解疑问作出解释

### 写作要点
- 开头必引用对方来文：你单位《关于……的请示》（文号）收悉。经研究，现批复如下：
- 态度明确：同意、原则同意、不同意，不可模棱两可
- 如部分同意，须说明不同意部分及理由
- 批复内容要有针对性，只回答请示中提出的问题
- 标题为「关于同意……的批复」或「关于……的批复」

---

## 十二、报告（行政公文类）

> 注：此处的「报告」指《党政机关公文处理工作条例》规定的 15 种法定公文之一，属上行文，区别于日常工作中广义的「报告」（调研报告、工作报告等，已在模板一至四中覆盖）。

```
[发文机关标志]
[发文字号]           签发人：[姓名]

[标题]

[主送机关]：

[正文：缘由 → 报告事项 → 结语]

特此报告。

附件：[附件名称]

[发文机关署名]
[成文日期]
```

### 适用场景
- 向上级机关汇报工作进展
- 反映某方面情况
- 答复上级机关的询问
- 向上级报送文件或物件

### 写作要点
- 「签发人」必须标注（上行文要求）
- 报告不得夹带请示事项（如需批复请用「请示」）
- 根据内容分为：工作报告、情况报告、答复报告、报送报告
- 工作报告：阶段性总结 + 下步计划
- 情况报告：发生了什么 + 怎么处理的 + 结果如何
- 答复报告：针对上级询问逐条回应
- 结语用「特此报告」，语气客观不卑不亢

---

## 十三、议案

```
[发文机关标志]
[发文字号]

[标题]

[主送机关]：

[正文：案由 → 方案 → 结语]

请审议。

附件：[附件名称]

[发文机关署名（盖章）]
[成文日期]
```

### 适用场景
- 各级人民政府向同级人大或其常委会提请审议事项
- 适用主体严格限定为政府机关，部门和个人不能使用

### 写作要点
- 使用范围极窄，仅限政府向人大提交
- 标题格式：「XX 人民政府关于提请审议……的议案」
- 正文：先说「为了……拟……」，再列出具体方案，最后「请审议」
- 附件通常是法规草案、人事任免名单等审议材料
- 成文日期为政府主要负责人签署日期

---

## 十四、决定

```
[发文机关标志]
[发文字号]

[标题]

[主送机关]：

[正文：缘由 → 决定事项 → 执行要求]

本决定自发布之日起施行。

附件：[附件名称]

[发文机关署名]
[成文日期]
```

### 适用场景
- 对重要事项作出决策部署
- 奖惩有关单位和人员
- 变更或撤销下级不适当的决定事项

### 写作要点
- 权威性强，用语果断、不容置疑
- 开头阐明决定的背景和依据（根据……，经……研究，决定如下：）
- 决定事项分条列出，条理清晰
- 涉及奖惩的决定，要写明依据和事实
- 执行要求明确时限和责任
- 标题通常为「关于……的决定」

---

## 十五、意见

```
[发文机关标志]
[发文字号]

[标题]

[主送机关]：

[正文：缘由 → 意见内容 → 结语]

以上意见，请结合实际情况贯彻执行。
（如无不妥，请批转各地各部门执行。/ 以上意见供参考。）

附件：[附件名称]

[发文机关署名]
[成文日期]
```

### 适用场景
- 对重要问题提出见解和处理办法
- 可用于上行、下行、平行，是公文中最灵活的文种

### 写作要点
- 方向灵活：上行意见→请求批转；下行意见→指导性文件；平行意见→参考建议
- 开头说明制定意见的背景、目的和依据
- 主体分条陈述具体意见，每条可含「原则要求 + 具体措施」
- 结语根据行文方向选择不同措辞
- 标题为「关于……的意见」或「关于……的实施意见」
- 下行意见可用「请认真贯彻执行」；上行意见多用「以上意见如无不妥，请批转」

## 二十六、超长报告分段生成策略

> 当报告预计超过 5000 字时，采用分段生成模式，避免单次输出质量下降。

### 策略流程

1. **先生成大纲**：与用户确认整体框架（一级标题 + 二级标题）
2. **逐章生成**：按章节顺序分批生成，每章 800-1500 字
3. **章末衔接**：每章结尾用过渡句为下一章做铺垫
4. **全文统稿**：所有章节完成后，整体通读，统一语言风格和措辞

### 用户提示

```
您要的报告预计约 [X] 字，建议分段生成以确保质量。
我将按以下顺序逐章完成：

第一章：[标题] （约 X 字）
第二章：[标题] （约 X 字）
……

现在开始第一章，完成后请您确认内容和方向，我继续下一章。
```

### 质量保障

- 每章生成后暂停，等待用户确认或修改意见
- 保持各章风格一致（同一套语气、用词、句式）
- 统稿时重点检查：标题对仗、数据一致性、逻辑连贯性

## 三十二、联合行文（多单位联合发文）

```
[发文机关标志：各联合发文单位名称，主办单位排列在前]
主办单位名称
联合单位A
联合单位B

[主办机关发文字号]              签发人：[多签发人按序排列]

[标题]

[主送机关]：

[正文：缘由 → 事项 → 责任分工 → 结尾]

附件：[附件名称]

[发文机关署名：按版头顺序自上而下排列]
[成文日期：最后签发机关负责人签发日期]
（印章：按版头顺序排列，主办在前，互不相交相切）
```

### 适用场景
- 同级机关就共同事项联合发文（如多部门联合部署专项行动）
- 党委与政府联合行文部署全局性工作
- 不相隶属机关之间商洽、协调跨部门事项
- 多单位联合开展检查、整治、督查等专项工作

### 版头排列规则

联合行文的发文机关标志可并用各发文单位名称，也可单独使用主办单位名称。并用时按下列顺序排列：

| 联合类型 | 排列顺序 |
|---------|---------|
| 党委 + 政府 | 党委在前，政府在后 |
| 政府 + 军队机关 | 军队机关在前 |
| 行政机关 + 人民团体/事业单位 | 行政机关在前 |
| 同级同类机关 | 按编制序列或单位级别排列 |
| 跨级机关 | 级别高的在前 |

> **主办单位规则**：无论上述何种排列顺序，**主办单位一律排列在最前**。

### 发文字号与签发人

| 要素 | 规则 |
|------|------|
| 发文字号 | 只使用**主办机关**的发文字号，联合单位不另编发文字号 |
| 签发人（上行文） | 多个签发人按**发文单位排列顺序**，从左到右、自上而下编排 |
| 签发人排列格式 | 每行排两个姓名，回行时与上一行第一个签发人姓名对齐 |
| 成文日期 | 署**最后签发机关负责人**的签发日期 |

### 印章布局

联合行文一般应加盖**所有**发文单位印章，主办单位印章排列在前。

| 印章数量 | 排列方式 |
|:---:|---------|
| 2 个 | 左右并排，主办单位印章在左 |
| 3 个 | 上一下二（主办在上）或品字形排列 |
| 4-6 个 | 分两行排列，每行最多 3 个，主办在第一行首位 |
| 7 个以上 | 分三行及以上排列，保持行距均匀 |

**排列要求**：
- 印章之间**互不相交、不相切**，保持均匀间隔
- 印章用红色，端正清晰，不得倒置或倾斜
- 最后一个印章**居中下压**发文机关署名和成文日期
- 印章不得压住正文

### 写作要点
- 正文由**主办单位**牵头起草，联合单位会签确认，会签意见应充分吸纳
- 事项表述兼顾各联合单位职责边界，避免越权或职责交叉
- 涉及多家分工时，正文中明确"由 XX 牵头、XX 配合"的责任分工
- 结尾用语按行文方向选择：下行文用"特此通知"；上行文用"妥否，请批示"；平行文用"特此函告"
- 主送机关可并列多个，按级别或编制序列排列
- 版记中应标注所有联合发文单位

### 常见错误

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 各联合单位各编发文字号 | 只使用主办机关发文字号 |
| 版头排列顺序错误（非主办单位在前） | 主办单位排列在最前 |
| 成文日期用最先签发日期 | 用最后签发机关负责人的签发日期 |
| 印章重叠或相交 | 印章互不相交、不相切，保持间隔 |
| 只盖主办单位印章 | 一般应加盖所有发文单位印章 |
| 联合单位职责表述交叉含糊 | 明确"牵头—配合"分工 |
