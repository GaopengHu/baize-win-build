## 六、引用规范

### 公文引用格式
```
根据《[文件全称]》（[发文字号]）精神……
根据《[文件全称]》关于……的要求……
按照《[文件全称]》的部署……
```

### 引用注意事项
- 首次引用必须使用文件全称
- 后续可用「该文件」「该意见」等指代
- 文件名称中的书名号不可省略
- 不确定文件名称时，用占位符「根据 XX 关于 XX 的要求」并提示用户自行补充
- **绝不编造文件名称和文号**
